# Design System: Argus

## Overview

**Creative North Star: "One Instrument, Five Dials"**

Argus is a single operating shell, a 232px sidebar, a 56px top bar and a scrolling main column of cards, tables and charts. Five visual worlds can dress that shell. **Classique** is the original dark/light trading-desk theme in `tokens.css` + `app.css`. The four alternatives live in `designs.css` and are switched by `<html data-design="eyes|metro|billets|paper">`: **Les cent yeux**, **Plan de métro**, **Série de billets**, **Working paper**. A world may only change type, palette, density and one signature move. Every control, number and page stays where it is, so a practitioner who switches worlds loses nothing and an evaluator sees a different face of the same engine.

The density is that of a working tool: 13.5px body, 9px table cell padding, a 14px card grid, tabular numerals everywhere numbers appear. Hierarchy comes from weight and a handful of small uppercase labels, never from big type. The one exception is the signature move each world places on the overview, directly under the page title: the surveillance map, the network map, the face value, the replicated-results table. Each is drawn from live data or from facts stated in the methodology document. None is decoration.

**Les cent yeux** is the default world for a first visit (`DEFAULT_DESIGN` in `web/src/lib/theme.tsx`, mirrored by the inline script in `index.html`). Switching worlds is an easter egg with no permanent control on screen: three quick clicks on the logo, or typing "argus" outside a text field, opens a transient menu (`.design-menu`, `DesignMenu` in `Layout.tsx`) next to the logo, listing the five worlds with a three-colour swatch each. It closes as soon as a world is picked, on Escape, or on a click outside; arrow keys move between items. The choice is persisted in `localStorage["argus-design"]` and can be forced by a `?design=` URL parameter that an inline script in `index.html` reads before first paint. Classique alone keeps the dark/light toggle (`localStorage["qplat-theme"]`). Each other world has one fixed scheme, declared in `DESIGNS` in `web/src/lib/theme.tsx`.

**Key Characteristics:**
- One shell, one component contract (`.card`, `.card-head`, `.card-title`, `table.data`, `.btn`, `.input-wrap`, `.segmented`, `.tabs`, `.badge`, `.chip`). Worlds override tokens first and selectors second.
- A world is a token block on `:root[data-design="…"]` plus a matching chart palette in `DESIGN_PALETTES`. The CSS and the JS must agree hex for hex.
- Navigation groups carry `data-group` (`marches`, `portefeuille`, `pricing`, `taux`, `recherche`, `reference`) on section labels, nav links and `.main`. Worlds that colour by section key off `--line`.
- Tabular numerals on every figure; up and down colours are always the `--good-ink` and `--critical-ink` pair plus an arrow glyph from the icon set, never colour alone.
- Every motion respects `prefers-reduced-motion`.

## Colors

Each world is a complete, self-contained set of roles. Pages and components only reference roles (`--page`, `--surface-1..3`, `--border`, `--border-strong`, `--text-primary/secondary/muted`, `--grid`, `--axis`, `--accent`, `--accent-soft`, `--accent-ink`, `--good`, `--good-ink`, `--critical`, `--critical-ink`, `--warning`, `--shadow`, `--radius`, `--radius-sm`, `--font`). They never reference a world's hex.

### Classique (original; `tokens.css`)
- **Graphite Desk** (classic-dark-page, surface-1..3): near-black page with three warm-grey panel steps. This is the dark default.
- **Bone Ledger** (classic-light-page, surface-1, surface-3): warm off-white ground for the light toggle, used when the OS prefers light or the user chose it.
- **Desk Blue** (classic-dark-accent / classic-light-accent): the single accent. It marks the active nav link (soft fill plus a 2px inset left bar), primary buttons, focus rings, links and the first chart series.
- **Signal Green / Signal Red** (good / critical, with lighter `-ink` variants for text): daily moves and P&L only.
- **Amber Warning** (classic-warning): alerts.

### Les cent yeux (`data-design="eyes"`, light)
- **Peacock Rail** (eyes-rail, eyes-rail-active, eyes-rail-text, eyes-rail-muted): the sidebar becomes a deep teal rail with pale-teal type. The active link is a lighter teal block, and card titles take the rail colour.
- **Cool Fog** (eyes-fog) ground under **white panels** (eyes-panel). Card heads use the faint tint (eyes-panel-tint).
- **Iridescent series**: **Cobalt** (eyes-cobalt, the accent), **Ocellus Gold** (eyes-gold, also the warning), **Emerald** (eyes-emerald, good), **Garnet** (eyes-garnet, critical), **Peacock Teal** (eyes-peacock-teal, the inner ring of every ocellus), **Violet**.

### Plan de métro (`data-design="metro"`, dark)
- **Midnight Enamel** (metro-enamel) page, **Night Chrome** (metro-chrome) on sidebar and top bar, three enamel panel steps.
- **Porcelain** (metro-porcelain): primary text, station fills, the active-station dot.
- **Line inks**, one per navigation group via `--line`: **Green** for Marchés and Portefeuille, **Scarlet** for Pricing, **Amber** for Taux/change/crédit (also the warning), **Violet** for Recherche and Référence. **Cobalt** is the accent and the default line. **Teal** exists only as a chart series.

### Série de billets (`data-design="billets"`, light)
- **Cool Paper** (billets-ground, billets-paper, billets-paper-tint) with **Banknote Ink** (billets-ink) text.
- **Denominations**, one hue per app section via `--line`: **20 Blue** for Marchés (also the default accent), **10 Red** for Portefeuille (also critical), **50 Orange** for Pricing, **100 Green** for Taux/change/crédit (also good), **500 Violet** for Recherche, **5 Grey** for Référence. **200 Yellow** is reserved for warnings.
- On the billets `.main`, `--accent` is re-pointed to the section's `--line`, so tabs, primary buttons and focus in a Pricing page all turn orange.

### Working paper (`data-design="paper"`, light)
- **Off-white Sheet** (paper-ground), the same value for page and panels: there are no boxes. **Margin Grey** (paper-margin) fills the sidebar.
- **Ink** (paper-ink) serves as primary text, `--border-strong` and the chart axis: rules are drawn in ink.
- **Burgundy Rubric** (paper-rubric): the accent, the active nav link text, the "Figure n." / "Tableau n." numbering and the brand mark.
- **Navy** (paper-navy) is chart series 1. Good, critical and warning are muted print tones.

### Named Rules
**The Role-Only Rule.** Components read `--accent`, `--good-ink`, `--surface-2` and the other roles, never a world's hex. A world that needs a new role adds a custom property in its own block (`--rail`, `--gold`, `--line`, `--ui-font`, `--sel`, `--scroll`). It does not hard-code the colour into a shared selector.

**The Mirrored Palette Rule.** ECharts cannot read CSS variables, so every world exists twice: the token block in CSS and a `ChartPalette` in `theme.tsx` (`PALETTES` for Classique dark and light, `DESIGN_PALETTES` per world). `surface`, `text`, `grid`, `axis`, `good` and `critical` must equal the CSS tokens, and `font` must equal `--font`.

**The Section Hue Rule.** In worlds that colour by section (metro, billets), the hue comes from `[data-group] { --line: … }` and nothing else. A band with white text on a section hue is deepened with `color-mix(in srgb, var(--line) 72%, #1c2230)` so it holds 4.5:1.

### Chart series (8 per palette, in order)
- Classique dark: `#3987e5 #d95926 #199e70 #c98500 #d55181 #008300 #9085e9 #e66767`. Diverging: `#e66767 / #383835 / #3987e5`.
- Classique light: `#2a78d6 #eb6834 #1baf7a #eda100 #e87ba4 #008300 #4a3aa7 #e34948`. Diverging: `#d03b3b / #f0efec / #2a78d6`.
- Eyes: cobalt, gold, emerald, violet, garnet, peacock teal, `#8c6a2b` bronze, muted. Diverging: garnet / `#e3ebe8` / cobalt.
- Metro: cobalt, scarlet, amber, green, violet, teal, porcelain, muted. Diverging: scarlet / `#34447a` / cobalt.
- Billets: 20 blue, 10 red, 50 orange, 100 green, 500 violet, 200 yellow, 5 grey, ink. Diverging: red / `#e4e7eb` / blue.
- Paper: navy, burgundy, `#5e7f3e` olive, `#b8860b` dark gold, `#6b4e9b` violet, secondary ink, `#a0522d` sienna, `#8a8f98` grey. Diverging: `#9b1c1c` / `#e8e6e0` / navy.

## Typography

**Display Font:** none; Argus has no display face. Hierarchy is weight-driven at small sizes.
**Body Font:** per world. Classique uses Inter Variable, eyes Hanken Grotesk Variable, metro Red Hat Text Variable, billets Public Sans Variable, paper Source Serif 4 Variable. Each falls back to system-ui (Georgia for paper). All are self-hosted through `@fontsource-variable`.
**Chrome Font (paper only):** Source Sans 3 Variable via `--ui-font`, applied to the sidebar, top bar, buttons, segmented controls, tabs, sub-navigation, badges, field labels and the design picker.
**Mono:** `ui-monospace, SF Mono, JetBrains Mono, Menlo` (`--mono`), used for formulas.

**Character:** a compact technical sans in four of the worlds and a working-paper serif in the fifth. Each world swaps only the family through `--font`. The ramp is shared.

### Hierarchy (shared ramp; world overrides noted)
- **Page title** (650, 20px, −0.01em): one per page. In billets it sits white inside the section-hue band. In paper it is serif 600.
- **Stat value** (600, 22px, tabular): KPI tiles. Billets prints them at 700, 26px, −0.02em like a denomination.
- **Body** (400, 13.5px / 1.45): everything, including table cells (tabular numerals on `table.data`). Paper raises it to 14.5px for the serif.
- **Card title** (600, 12.5px, uppercase, 0.06em, secondary colour): the panel name. Eyes colours it rail teal at 0.05em, metro uses porcelain at 0.1em, billets uses ink at 700. Paper drops uppercase for **small caps at 15px**, prefixed with the rubric numbering.
- **Label** (500, 11.5px, uppercase, 0.05em, muted): table headers, stat labels, field labels (field labels are not uppercase). In paper, table headers are 13px small caps in ink.
- **Nav section** (10.5px, uppercase, 0.09em, muted): group labels in the sidebar. Metro gives them porcelain text, 0.12em tracking and an 18×4px line swatch. Billets turns them into white 700 text on a 2px-cornered section-hue band.

### Named Rules
**The Tabular Rule.** Every number that can change sits in `.num`, `table.data` or an input, all of which carry `font-variant-numeric: tabular-nums`. No world may switch to a family without tabular figures.

**The Small Type Rule.** Nothing on an operating page exceeds 26px, except a world's overview signature (the billets face value at 76px, 48px on a phone).

## Layout

The shell is a CSS grid: `232px | 1fr` columns and `56px | 1fr` rows, with areas `side top / side main`. The window never scrolls; `.main` scrolls with 22px 24px 40px padding. Pages open with `.page-head` (title + subtitle, 18px below) and continue in `.grid` blocks with a 14px gap (`cols-2/3/4`) or `.split` (a 320px form column beside the results). Cards pad 12px 16px in the head and 14px 16px in the body.

Responsive steps: at 1280px, 4 and 3 columns become 2, and the surveillance map stacks its table under the ocelli. At 1180px the market chips leave the top bar. At 1080px the sidebar collapses to a 64px icon rail (labels, section labels and footer hidden), `.split` and `cols-2` go single-column, and the metro station ring shrinks to 6px. At 720px the shell becomes top bar / horizontal nav strip / main with 16px gutters, every grid goes to one column, the metro map scrolls sideways at a 760px minimum width, and the replicated-results table stacks row by row.

Worlds do not change the grid. The only spatial changes a world makes are internal: paper removes card side padding so content aligns on the text column, and billets wraps the page head in a 16px 20px band.

## Elevation & Depth

Depth is one token, `--shadow`, applied to `.card`. Each world chooses how much of it to keep: Classique dark uses an inset hairline plus a deep drop, Classique light and eyes use a two-layer whisper, metro uses an inset porcelain hairline plus a navy drop, billets keeps a 1px print shadow, and paper uses `none`. State depth is limited to rings: the input focus ring (`0 0 0 3px var(--accent-soft)`), the selected segment (`0 0 0 1px var(--border-strong)`) and the open-market dot halo.

### Shadow Vocabulary
- **Classique dark card** (`0 1px 0 rgba(255,255,255,0.03) inset, 0 8px 24px rgba(0,0,0,0.35)`)
- **Classique light card** (`0 1px 2px rgba(11,11,11,0.04), 0 6px 20px rgba(11,11,11,0.05)`)
- **Eyes card** (`0 1px 2px rgba(11,31,36,0.05), 0 6px 18px rgba(11,31,36,0.05)`)
- **Metro card** (`0 1px 0 rgba(244,241,232,0.04) inset, 0 8px 24px rgba(5,10,26,0.45)`)
- **Billets card** (`0 1px 2px rgba(28,34,48,0.06)`)
- **Paper** (`none`)

### Named Rules
**The One Shadow Rule.** A world sets `--shadow` once. Components never compose their own drop shadows.

## Shapes

Corners are a per-world pair, `--radius` for cards and `--radius-sm` for controls and nav links: Classique 10/6, eyes 8/5, metro 6/4, billets 3/2, paper 0/2. Badges and chips stay pill-shaped (999px) in every world, and segmented buttons keep 4px. World-specific forms: the eyes brand mark becomes a circle with a concentric gradient (pupil, cobalt, emerald, gold); the metro brand mark is a scarlet roundel; billets and paper brand marks are near-square blocks in ink and rubric. Paper replaces the card box with a 1.5px ink top rule and a 0.5px hairline under the head (0.5px for stat tiles). Tables in paper are booktabs: 1.5px ink rules above and below and a 0.75px rule under the header.

## Components

The shared contract lives in `app.css` and is never forked per world. Worlds restyle it from `designs.css` with `:root[data-design="…"] .selector` rules.

### Buttons
- **Shape:** `--radius-sm`, 1px `--border-strong` stroke, 7px 12px padding (7px for icon-only), 500 weight.
- **Default:** `--surface-2` fill, `--surface-3` on hover. **Primary:** `--accent` fill, white text, `brightness(1.08)` on hover. **Ghost:** transparent, `--surface-2` on hover. Disabled is 50% opacity.

### Chips and Badges
- **Badge:** 11px 600 pill on `--surface-3`. The `.accent` variant uses `--accent-soft` with `--accent` text, for example the US/EU market tag in the top bar.
- **Chip:** 12px pill with a `--border-strong` outline and an 8px colour dot. The `.on` state takes `--surface-2` and primary text.

### Cards / Containers
- **Corner Style:** `--radius`. **Background:** `--surface-1`. **Border:** 1px `--border`. **Shadow:** `--shadow`.
- **Head:** a flex row of title and actions with a 1px bottom border. Eyes tints the head with `--surface-2`. Paper removes every box, leaving only rules.

### Inputs / Fields
- **Style:** `.input-wrap` on `--surface-2`, 1px `--border`, `--radius-sm`, 7px 10px padding, tabular numerals, optional muted suffix.
- **Focus:** the border turns `--accent` with a 3px `--accent-soft` ring (0.12s border transition).
- **Segmented control:** a `--surface-2` track. The active segment is `--surface-1` with a 1px `--border-strong` ring.
- **Tabs and sub-navigation:** a 2px bottom bar in `--accent`. Eyes paints it rail teal; billets paints it the section `--line`.

### Navigation
- **Sidebar:** brand block, grouped `.nav-link`s (17px lucide icon, 500 label, 8px 10px), and a footer with data freshness.

### Adding a fifth world
1. Add the id to `Design` and `DESIGNS` in `theme.tsx` with its label and fixed `mode`. Add a `DESIGN_PALETTES` entry whose surface, text, grid, axis, good, critical and font mirror the CSS.
2. Add the id to the `?design=` regex in `web/index.html`.

## Do's and Don'ts

### Do:
- **Do** express a world as tokens first. Override a shell selector only where the world's one signature move needs it.
- **Do** keep `DESIGN_PALETTES` and the CSS token block in lockstep, hex for hex.
- **Do** colour by section only through `data-group` and `--line`, and deepen any white-text band with `color-mix(in srgb, var(--line) 72%, #1c2230)`.
- **Do** pair every up or down colour with the arrow glyph from `Delta`.
- **Do** keep each signature truthful: encodings on fixed scales (the ocellus √-vol ramp, full iris at 3%), stations that follow real dependencies, results that are in the methodology document.
- **Do** give every hover or transition a `prefers-reduced-motion: reduce` fallback, using `cubic-bezier(0.16, 1, 0.3, 1)` for state moves.

### Don't:
- **Don't** edit `tokens.css` or `app.css` to make a world work. Classique is the untouched original, and a world that needs a shell change scopes it under `:root[data-design="…"]`.
- **Don't** move, hide or reorder controls, nav items or numbers per world. Worlds lend type, palette, density and one signature only.
- **Don't** add a dark/light toggle to a non-Classique world. Each has one fixed scheme.
- **Don't** let paper grow boxes or drop shadows. Its structure is rules, ink and numbering.
- **Don't** show the metro line swatch or the billets band on `.nav-section` used inside `.main`. Those labels are reset to plain muted text.
- **Don't** invent figures for the paper results table or any signature; nothing there may claim outside use.
